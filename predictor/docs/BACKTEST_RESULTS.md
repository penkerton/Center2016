# Результаты исторического тестирования

## Протокол

- Данные: сыгранные матчи 2016 и 2017 г.р. за 2024/2025–2026/2027.
- Разогрев: 120 первых матчей (модели ещё не оцениваются).
- Переобучение логистической регрессии: каждые 30 матчей, только на прошлом.
- Пересчёт Пуассона: каждые 40 матчей, только на прошлом.
- Проверено матчей: **2 313** (2025-01-09 — 2026-11-01).
- Всего в базе 2 547 сыгранных матчей; технические поражения исключены из
  обучения и проверки, остальные ушли в разогрев.
- Исходы: 1 302 победы хозяев, 75 ничьих, 1 056 побед гостей.
- Веса ансамбля подбирались на первых 70% проверочных матчей; отложенные 30%
  (694 матча) — честная проверка.

## Контрольный матч 22449

«Созвездие 2016» — «Центр 2016», 2026-10-31, 09:45, 4×4, группа В.

Прогноз (отсечка 2026-10-31 09:45, 2 519 матчей в истории):

| Исход | Вероятность |
|---|---:|
| Победа «Созвездия» | 40,3% |
| Ничья | 8,4% |
| Победа «Центра» | **51,3%** |

Факт: 13:18, победа «Центра». Прогноз верный, Brier 0,406. Хеш признаков
`8a86087b…876446`, файл `predictions/match_22449.json` создан до сверки и не
перезаписывается.

Оговорка: результат матча стал виден при исследовании сайта ещё до запуска
прогноза, поэтому это не «слепой» тест. Независимость прогноза обеспечивается
кодом: в историю попадают только матчи с началом раньше отсечки, что
проверяется тестом `test_no_leakage` и хешем признаков.

## Как воспроизвести

```powershell
python main.py collect
python main.py backtest
python main.py predict --match 22449 --cutoff "2026-10-31T09:45:00+03:00" --save --immutable
python main.py verify --match 22449
```

Полные данные — `reports/backtest.json` и `reports/backtest_predictions.csv`
(2 313 строк с вероятностями всех моделей).

## Что это значит

- 0,77 accuracy — не «предсказание любого счёта», а выбор исхода из трёх.
- Для равных команд вероятность близка к 50/50, и уверенность падает.
- На малых группах (Г/Д/Ж) и формате 5×5 выборка слишком маленькая для
  сильных выводов.
- Модель не знает составов на конкретный матч; ручная корректировка в
  интерфейсе меняет только вклад игроков, а не «угадывает» травмы.
- Сверхдисперсия голов велика (среднее 9,05, дисперсия 84,90, отношение 9,38),
  поэтому Пуассон — приближение; Negative Binomial не реализован.
