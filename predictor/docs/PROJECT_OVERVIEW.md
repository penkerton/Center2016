# FHM Hockey Predictor — обзор проекта

## Назначение

Локальная программа для прогнозирования победителя матчей детских хоккейных
команд ФХМ (2016 и 2017 г.р.). Пользователь выбирает две команды и дату — система
показывает вероятность победы каждой команды, ничьей, объясняет факторы и
позволяет скорректировать состав.

Проект вырос из статического сайта команды «Центр»: сайт показывает таблицу,
матчи и статистику, а `predictor/` добавляет базу, рейтинги, модели, backtest и
интерфейс прогноза.

## Чего в проекте нет

- Построчных составов на каждый матч: сайт подгружает их JS-модулем, в HTML их
  нет. Поэтому участие игрока в конкретной игре достоверно неизвестно.
- Надёжных передач: в заявках поле передач почти всегда 0.
- Вратарской статистики (кроме `totalMissed` в заявке) и времени на льду.
- Официальных документов о переходах: история строится по смене клуба между
  сезонами.
- Гарантии высокой точности на будущих матчах: выборка ограничена, интервалы
  широкие.

Подробно — в [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md).

## Быстрый старт

```powershell
cd Other\center\predictor
python -m pip install -r requirements.txt
python main.py collect
python main.py backtest
.\start.bat
```

Интерфейс откроется на `http://localhost:8501`. Страница для GitHub Pages —
`predictor/index.html`, локально с кнопками обновления — `bridge.bat`
(`http://127.0.0.1:8765/`, пароль `refresh`).

## Принципы

1. **Никаких выдуманных данных.** Всё, что показывает система, приходит из
   официальных ответов ФХМ и хранится в SQLite.
2. **Отсечка по времени.** Для прогноза матча используются только игры, начавшиеся
   раньше него; это проверяется тестом и хешем признаков.
3. **Честные метрики.** Точность считается на хронологической выборке, а не на
   обучении; веса ансамбля подбирались на первых 70% проверочных матчей.
4. **Локальность и приватность.** Только публичные спортивные данные, без
   контактов и фотографий; рабочие данные исключены из git.
