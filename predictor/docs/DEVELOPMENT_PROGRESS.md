## Проблемы и решения

| Проблема | Решение |
|---|---|
| 429 при частых запросах | пауза 1,2 с, адаптивное увеличение до 12 с, 5 повторов, кеш |
| `limit=100` → HTTP 400 | страницы по 50 |
| даты `2020-01-06` | год выводится из сезона, а не из первых двух цифр |
| 550 матчей не записались | исправлен разбор даты, пересобран сезон |
| зависший запрос | таймауты (10, 35), повтор, отдача устаревшего кеша |
| SQLite в потоках Streamlit | `check_same_thread=False` |
| шумные старые замечания | удалены после успешного пересбора |

  статистики и пересчёта модели.
