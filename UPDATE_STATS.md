# Обновление статистики игроков 2016 г.р.

Этот проект использует файл `all_2016_players_season5.js` как источник данных для таблицы на странице.

Скрипт `update_fhm_2016_stats.ps1` автоматически:
- получает все команды 2016 г.р. за выбранный сезон;
- получает составы команд;
- оставляет игроков нужного года рождения;
- собирает поля: игрок, группа, команда, игры, голы;
- сортирует по голам (убывание), затем по играм (убывание), затем по имени;
- обновляет файлы `all_2016_players_season5.json` и `all_2016_players_season5.js`.

## Быстрый запуск (PowerShell)

В папке проекта выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\update_fhm_2016_stats.ps1
```

## Параметры

По умолчанию:
- `SeasonId = 5` (сезон 2026/2027)
- `TeamYear = 2016` (команды 2016)
- `BirthYear = 2016` (игроки 2016 г.р.)

Пример запуска с параметрами:

```powershell
.\update_fhm_2016_stats.ps1 -SeasonId 5 -TeamYear 2016 -BirthYear 2016
```

## Что проверять после запуска

1. В консоли должно быть:
   - количество обработанных команд;
   - количество строк игроков;
   - пути к двум выходным файлам.
2. Обновляются файлы:
   - `all_2016_players_season5.json`
   - `all_2016_players_season5.js`
3. После перезагрузки `index.html` таблица показывает обновлённые данные.

## Если API временно недоступен

- Запустите скрипт повторно через 1–2 минуты.
- Можно немного увеличить паузу между командами:

```powershell
.\update_fhm_2016_stats.ps1 -DelayMs 250
```
